### 2. Penjelasan Service
### SaaS (Software as a Service)
#### Pengguna langsung memakai aplikasi melalui internet tanpa perlu instalasi. Contoh Google Docs digunakan untuk membuat dan mengedit dokumen secara online.
### PaaS (Platform as a Service)
#### Penyedia menyediakan platform untuk menjalankan aplikasi. Developer hanya fokus membuat kode tanpa mengelola server. Contoh Heroku.
### IaaS (Infrastructure as a Service)
#### Penyedia menyediakan infrastruktur seperti server virtual, storage, dan jaringan. Contoh Amazon EC2.
